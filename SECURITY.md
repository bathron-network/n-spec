# Security policy

N-SPEC is a specification (v0.7, Architecture Frozen Candidate, not mainnet-qualified). Reports about the specification itself —
a counterexample, an invariant violation, an ambiguity that could make two conforming implementations diverge — are welcome.

**Report privately.** Do not open a public issue for anything exploitable.

- Preferred: GitHub private vulnerability reporting on this repository (*Security* tab → *Report a vulnerability*).
- Or email: `security@bathron.org`.

Implementation issues in the public node belong to [bathron-core](https://github.com/bathron-network/bathron-core/blob/main/SECURITY.md).
